# Practicing IT-Support on SysDesks

<img width="1918" height="1027" alt="image" src="https://github.com/user-attachments/assets/5cc2ff63-45f1-4550-be6d-d174ed39ca4d" />


In this environment, you get to claim tickets with problems to solve as an IT Specialist/Support/Staff.

- You will claim tickets, trouble shoot.
- Solve the Technical issues
- Document the issue and actions, or escalate if needed

You get to work with server, active directory and other tools. 

One thing i like about it is that you can have a simulated chat or call with the employee who created the ticket, so you can try to know more about the problem they are facing which makes everything feels more interactive.
